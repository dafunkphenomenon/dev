ITUnity Development Channel Repository
======================================

This GitHub repository holds code samples related to articles written for the [ITUnity Development Community](http://www.itunity.com/community/development).

## Dev Container for .NET 9 & Umbraco Development

This repository includes a comprehensive VS Code dev container configuration for developing Umbraco applications and custom .NET APIs with .NET 9.

### Quick Start

1. Install [Docker Desktop](https://www.docker.com/products/docker-desktop) and [VS Code](https://code.visualstudio.com/)
2. Install the [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)
3. Open this repository in VS Code
4. Click "Reopen in Container" when prompted (or use Command Palette: `Dev Containers: Reopen in Container`)
5. Wait for the container to build (first time takes several minutes)

### What's Included

- ✨ **.NET 9 SDK** - Latest .NET SDK with all development tools
- 🚀 **Node.js 20** - For frontend asset management
- 🗄️ **SQL Server 2022** - Developer edition in a separate container
- 🔧 **Development Tools** - Entity Framework, SQL tools, Azure CLI, Git, and more
- 📦 **VS Code Extensions** - 15+ pre-installed extensions for .NET and web development
- 🖼️ **Image Processing** - libgdiplus for Umbraco media handling
